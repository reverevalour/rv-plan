# RV Plan v0.1

Приватний local-first PWA для iPhone.

## Що вже працює
- Today / Tomorrow / Later / All
- швидке додавання задач
- розбір українських фраз: «завтра о 9:00 ...», «сьогодні о 18 ...», «післязавтра ...», дати типу 12.10
- авто-категорії RVMOVE / Revere Valour / Documents / Personal
- голосовий ввід через Web Speech API, якщо Safari його надає; інакше — системне диктування iPhone
- локальне збереження на пристрої
- offline-кеш
- badge на іконці, де підтримується
- резервна копія JSON
- сповіщення, коли додаток активний

## Важливо про фонові нагадування
Повноцінні нагадування при повністю закритому PWA потребують Web Push з сервера. Service Worker уже має обробник push, але сервер підписки/відправки ще треба підключити.

## Як поставити на iPhone
1. Опублікувати цю папку на HTTPS (GitHub Pages / Netlify / Cloudflare Pages / Vercel).
2. Відкрити адресу у Safari на iPhone.
3. Share → Add to Home Screen → Open as Web App.
4. Відкрити RV Plan з іконки.

## Приватність v0.1
Задачі не відправляються в хмару. Вони лежать у localStorage конкретного браузерного профілю/вебдодатка. Інша людина, яка відкриє той самий URL на іншому телефоні, не побачить ваші задачі.
